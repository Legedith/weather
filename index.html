What about WeatherNext 3?+

Google announced WeatherNext 3 on 3 September 2026. Open-Meteo currently documents WeatherNext 2, not 3. The optional Google Weather API uses a blend of models and does not return a model version.

Connecting Google requires a server-side API key. This page never stores one.

Privacy & data

Saved places, preferences, and your last selected pin stay in this browser. Location is requested only when you press “Use my location”. Search text and coordinates are sent to the selected geocoding and weather services. Opening the map requests OpenStreetMap tiles. Sharing includes your selected coordinates in the link. No Google forecast responses or API keys are stored in your browser.
